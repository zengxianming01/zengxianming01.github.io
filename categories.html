Categories

全部分类

这里是所有长期栏目的入口。新增分类时，先更新 _data/categories.yml，首页和分类页都会同步变化。

{% for category in site.data.categories %}
{{ category.label }}

{{ category.name }}

{{ category.description }}

{% for tag in category.tags %} {{ tag }} {% endfor %}
{% endfor %}

Posts

按分类浏览文章

每篇文章的 front matter 使用 category 对应上面的 slug，就会出现在对应栏目里。

{% for category in site.data.categories %} {% assign category_posts = site.posts | where: "category", category.slug %}
{{ category.label }}

{{ category.name }}

{% if category_posts.size > 0 %} {% for post in category_posts %}

{{ post.title }}

{% endfor %} {% else %}

这个栏目还没有文章。

{% endif %}
{% endfor %}
